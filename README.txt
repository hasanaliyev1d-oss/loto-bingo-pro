# Loto Bingo Pro

## Fayllar
- `index.html` — oyunun görünüşü
- `server.js` — oyun serveri
- `package.json` — Node.js kitabxanaları və start əmri

## Render-də yerləşdirmə
1. Bu üç faylı GitHub repozitoriyasının əsas qovluğuna yüklə.
2. Render-də New + → Web Service seç və GitHub repozitoriyasını qoş.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. Environment: Node
6. Deploy bitəndə Render-in verdiyi `https://...onrender.com` ünvanını aç.

Oyun şifrəsi: `666`. Maksimum 6 oyunçu. Hər oyunçu maksimum 3 pulsuz kart götürə bilər.
Bu demo oyun real pul və depozit sistemi istifadə etmir. Oyunçu siyahısı və raund məlumatları server yaddaşında saxlanılır; server yenidən başladıqda sıfırlanır.
